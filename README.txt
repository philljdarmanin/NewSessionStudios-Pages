# New Session Studios favicon pack

Generated from a clean transparent version of the supplied NS icon.

## Recommended usage

Copy these files into the root of your website:

- favicon.ico
- favicon-16x16.png
- favicon-32x32.png
- apple-touch-icon.png
- android-chrome-192x192.png
- android-chrome-512x512.png
- android-chrome-512x512-maskable.png
- site.webmanifest

Then paste the contents of favicon-html-snippet.txt into the <head> of your HTML pages.

## Notes

- Browser favicon PNG/ICO files use transparent corners.
- apple-touch-icon.png uses a solid background because iOS home-screen icons usually look cleaner that way.
- android-chrome-512x512-maskable.png has extra padding so Android can safely crop it into different icon shapes.
